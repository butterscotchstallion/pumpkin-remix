# Pumpkin, Remixed

A responsive pumpkin character studio with a pointer-enabled sketch canvas, undo and erase tools, four visual style previews, a comparison slider, a four-style gallery, downloads, and a 13-second demo sequence.

## Run

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

This is an interactive frontend demo. The character is a pre-generated AI illustration; style options apply local visual treatments. The Transform action simulates generation and does not submit the drawing to an AI service. “Keep my weirdness” is a UI setting ready for a future generation integration.

Artwork: `public/pumpkin-clay.png`, generated with the built-in image generation tool. Prompt: adorable handmade claymation pumpkin creature, lopsided orange body, tall crooked green stem, mismatched eyes, broad goofy smile with one tooth, tiny arms and feet, tactile plasticine texture, warm cream studio background, no text.
